## 🚀 Featured Project

### ♟️ ChessRL
A reinforcement learning chess agent built with Python and PyTorch.

The project explores PPO, custom board-state representations, legal move masking, reward design, and self-play training.

[View ChessRL on GitHub](https://github.com/Ventheol/ChessRL)

*An experimental project. The agent can play complete games, but its playing strength has not been formally evaluated.*
